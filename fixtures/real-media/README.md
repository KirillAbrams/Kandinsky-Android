# Фото и видео для проверок на телефоне

В [списке оригиналов](manifest.json) восемь фотографий, два видео и одна анимация. Для каждого файла указаны автор, источник, лицензия, размер в байтах и контрольная сумма. Эти файлы нужны, чтобы проверить просмотр и сохранение на телефоне.

Чтобы сверить оригинал на Mac, выполни в этой папке `shasum -a 256 ИМЯ_ФАЙЛА` и сравни результат с полем `sha256` в списке. Уменьшенная копия для проверки загрузки описана [отдельно](cached-preview-source.json).
