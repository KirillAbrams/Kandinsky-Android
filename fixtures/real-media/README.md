# Примеры фото и видео для проверок

В manifest.json для каждого файла указаны автор, ссылка на оригинал, лицензия, размер и контрольная сумма. В наборе восемь фотографий, два видеоролика и один анимированный отрывок. Используй сведения об авторстве и распространяй файлы на условиях указанной для них лицензии.

Ролик editor-rotation90.mp4 получен из первого видео изменением поворота кадра. Файл с окончанием .source.json описывает исходник и преобразование. Материалы используются для проверок просмотра и хранения на телефоне.

Чтобы проверить отдельный файл, сравни его размер и SHA-256 со значениями в [manifest.json](manifest.json). На Mac команду `shasum -a 256 ИМЯ_ФАЙЛА` можно выполнить из этой папки.
